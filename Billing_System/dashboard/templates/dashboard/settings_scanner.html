Bluetooth HID Wireless Scanners

Bluetooth barcode scanners operate in HID (Human Interface Device) Keyboard Profile. Once paired to your terminal computer, tablet, or phone, every scan types directly into the browser buffer followed by an automatic Enter keystroke.

1. Enable HID Mode
Scan the "Enter Bluetooth HID Mode" barcode in your scanner's printed quick-start manual.
2. Pair via OS Bluetooth
Open Windows / macOS / Android Bluetooth settings, search for your scanner model, and click Pair.
3. Instant POS Ready
Open POS Checkout. Barcodes are automatically captured hands-free without clicking any buttons.

Mobile Camera Access: HTTPS & Security Requirements

Modern mobile operating systems and browsers (iOS Safari, Android Chrome) enforce a strict Secure Context requirement: camera hardware cannot be accessed over plain HTTP on LAN IP addresses. Over plain HTTP, cashiers can use the fast Manual Barcode Input on the companion screen.

Production Recommendation:
For live store operations, host the POS behind a standard domain (or local split-DNS) with a publicly trusted SSL certificate (e.g., Let's Encrypt via Nginx, Caddy, or Cloudflare). Mobile devices will access the camera seamlessly without any custom certificate installation.
Local Development TLS & Root CA Security Notice:
Trusting a root Certificate Authority (CA) allows that CA to sign certificates for any website. Never download or install unknown certificate files from the internet. When testing locally, only trust a CA generated directly on your own development machine using mkcert, and never share private key files (rootCA-key.pem).
1. Install on host: choco install mkcert
2. Generate local cert: mkcert -install && mkcert {{ network_info.lan_ip }} localhost 127.0.0.1
3. Run TLS dev server: python manage.py runserver_plus --cert-file {{ network_info.lan_ip }}+2.pem --key-file {{ network_info.lan_ip }}+2-key.pem 0.0.0.0:8000
Native Mobile Client Alternative: A native Android companion app (using CameraX / ML Kit) can communicate directly with the POS REST API over LAN without browser WebRTC/getUserMedia restrictions.
